## 这是什么

**「开源 Open Source」** 是一个面向交易者的学习与工具平台：免费资源先给 —— TV 指标、周末实盘观摩、量化信号一览；进阶再走一周集训课（定金预约、人工核验、可退定金）。主讲老师 **Cami Chan** 真人实盘背书。首页还有宣传片和主题曲 MV《我是交易员》。

## 核心功能

- **🧭 免费 TV 指标 · 12 款** — 聪明钱成交量异动、动态成交量分布关键价位、放量突破目标位、流动性扫单猎手、水墨系列等，填 TradingView 用户名即可免费申请，**每天更新一款**
- **📈 量化与信号源** — 财神系列信号源 + 老师实盘曲线公开可查；**每周六、日可免费领取老师实盘观摩账户**
- **🖥 软件工具 · 单练习神器** — 一个中文总控窗口同时管理多个独立 MT5，1 个喊单账号同步多个跟随账号（开仓 / 平仓 / 手数 / 止损止盈）
- **🎓 一周集训课** — Cami Chan 主讲（3 年交易经历 · 1,000 美金起步），涵盖交易知识、做单教学与模拟盘实操；每半月一期，定金预约 · 人工核验 · 支持退定金
- **🏦 合作券商** — TMGM、AXPM、GFS，机构简介、监管牌照与核心优势一览
- **🤝 交易员计划 / IB 返佣 / 积分权益** — 从学习到职业化的完整路径
- **💬 AI 在线客服** — 7×24 小时解答平台使用问题，实时读取最新平台数据
- **🌗 深色模式** — Telegram 风格简洁界面，浅色 / 深色随你切换
